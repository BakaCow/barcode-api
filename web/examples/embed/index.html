    One script to add the camera

    Place this where the scanner should appear on an HTTPS page. Keep the script URL pointed at your deployed scanner server.

    No build step or API key is needed.

    Connect a confirmed scan to your app

    The script installs the camera panel. Listen for its event to connect it to your own product lookup:

    document.addEventListener('barcode:scan', (event) => {
  const { scanId, format, text } = event.detail;
  // Look up the exact format + text in your catalogue.
  // Deduplicate scanId on your backend before changing stock.
});

    A confirmed scan pauses until the user chooses Scan another. Confirmation does not verify a product’s price, stock or validity.

    The page and scanner server must use HTTPS. Your website must allow the scanner frame and delegate camera permission. The hosted embed needs its assets to load online; use the self-hosted SDK when your application needs managed offline startup.
